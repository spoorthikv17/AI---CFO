## 📌 Overview

**AI CFO** is an intelligent financial management application designed to simplify financial analysis and support smarter business decisions.

The application combines Python, data analytics, machine learning, financial forecasting and AI-powered insights to transform financial transaction data into meaningful information.

It provides an interactive environment for monitoring financial performance, understanding trends and exploring future financial possibilities.

## 🎯 Problem Statement

Traditional financial tracking often requires manual calculations and separate tools for understanding income, expenses and profitability.

AI CFO brings financial information and intelligent analytical capabilities together in one application to make financial monitoring and decision-making easier.

## ✨ Key Features

### 📊 Financial Analytics

* Interactive financial dashboard.
* Income and expense monitoring.
* Profit and financial performance analysis.
* Category-wise expense analysis.

### 🔮 Financial Forecasting

* XGBoost-based forecasting.
* Historical financial trend analysis.
* Future income predictions.
* Model evaluation using MAE, RMSE and R².

### 🤖 AI-Powered Intelligence

* AI-generated financial insights.
* Intelligent financial recommendations.
* AI CFO chatbot for financial questions.

### 🚨 Risk & Anomaly Analysis

* Identification of unusual financial patterns.
* Financial risk indicators.
* Expense monitoring.

## 📈 Model Evaluation

The forecasting model is evaluated using:

* **MAE:** Mean Absolute Error.
* **RMSE:** Root Mean Squared Error.
* **R²:** Coefficient of Determination.

These metrics help assess the accuracy of financial predictions.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/spoorthikv17/AI---CFO.git
```

### 2. Navigate to the project directory

```bash
cd AI---CFO
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows:**


### 5. Install dependencies

```bash
pip install -r requirements.txt
```

Follow the entry-point instructions for the actual dashboard and backend in the project.
